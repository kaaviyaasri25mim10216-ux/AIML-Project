# 💰 Loan Repayment Prediction

A machine learning project dedicated to predicting the likelihood of a loan being fully repaid by the borrower. This system helps financial institutions assess risk and make informed lending decisions.

---

## ✨ Overview

This repository contains a complete end-to-end analysis and modeling pipeline, from initial data exploration to final model evaluation. The primary deliverable is a predictive model that classifies loan applicants into 'Fully Paid' or 'Not Fully Paid' categories.

## 🎯 Key Goals

* **Data Preprocessing:** Clean and prepare the `loan_data.csv` dataset.
* **Exploratory Data Analysis (EDA):** Visualize key relationships and patterns in the data.
* **Model Training:** Implement and tune a classification algorithm (e.g., Logistic Regression, Random Forest, or K-Nearest Neighbors).
* **Performance Evaluation:** Achieve a robust model with high predictive accuracy (initial result suggests **~84.5% accuracy**).

## 🛠️ Tech Stack

* **Language:** Python
* **Data Manipulation:** `pandas`, `numpy`
* **Modeling:** `scikit-learn`
* **Visualization:** `matplotlib`, `seaborn`
* **Environment:** Jupyter Notebook (`loan-repayment-prediction.ipynb`)
